# 오픈소스마케팅 회사 소개 덱

전 직원이 함께 보는 자리에서 쓰는 31장짜리 덱입니다. 영업 자료가 아닙니다. 무엇을 했고, 누구와 했고,
국가 지원사업을 어떻게 굴리고 있고, AI를 어디까지 쓰고 있고, 어디로 가는지를 순서대로 설명합니다.

## 근거

| 부 | 근거 |
|---|---|
| 1부, 2부 | 2026년 2월 회사소개서와 osoma.kr. 프로젝트 53건은 소개서 연혁의 2022년부터 2025년까지의 목록입니다 |
| 3부 | 2026년 관광기업 데이터와 AI 활용 지원사업 슬랙 워크스페이스. 채널 구조, 봇 리마인드, 회차 등록 형식, 진행률 기준표, 월간 보고 일정에서 뽑았습니다 |
| 4부 | 같은 워크스페이스의 컨설팅 기록. 실제 설치물과 기업이 고른 도구, 구독 설계 방식입니다 |
| 5부 | 소개서에 없는 내용이라 별도로 정한 방향입니다 |

산업군 분류는 연혁 53건을 성격으로 묶은 것입니다. 유통과 커머스 12건, IT와 금융 13건, 교육과 공공
10건, 제조와 서비스 18건이고 넷을 합하면 53건이 됩니다.

## 구성

| 부 | 장 | 내용 |
|---|---|---|
| 1부 그동안 한 일 | 1~8 | 표지, 차례, 회사 개요, 네 갈래의 일, 남기는 결과물 여섯, 구축 여섯 단계, 그로스가 푸는 문제, 연혁 |
| 2부 고객사와 산업군 | 9~13 | 53건을 넷으로, 유통과 커머스, IT와 금융, 교육과 공공, 제조와 서비스 |
| 3부 지원사업을 운영하는 방식 | 14~21 | 사업 개요, 판 깔기, 일정 관리, 주간 운영, 진행률 기준표, 보고 세 층, 변경 관리, 3년치 운영 |
| 4부 지금 AI를 쓰는 수준 | 22~27 | 달라진 일, AI를 심는 다섯 단계, 실제 설치물, 기업이 쓰는 도구, 구독 설계, 내부 활용 |
| 5부 앞으로 | 28~31 | 두 갈래, AX를 주력으로, 도구를 제품으로, 마무리 |

## 아직 비어 있는 것

21장의 연도별 성과 수치가 비어 있습니다. 2024년과 2025년 지원사업의 결과 수치는 슬랙에 남아 있지
않아 사업 종료 보고서에서 받아 채워야 합니다.

## 만들기

```bash
python3 build_deck.py            # 본문_소개.md 를 읽어 덱을 만듭니다
python3 build_deck.py --approve  # 대기 문장을 검수하고 고친 뒤 승인합니다
python3 build_deck.py --export   # 코드 쪽 글로 본문_소개.md 를 다시 뽑습니다. 파일의 수정이 지워집니다
python3 build_deck.py --print    # 인쇄 전용 판
python3 export_pdf.py            # 한 장 한 쪽으로 PDF를 찍습니다. 구글 크롬과 pypdf가 필요합니다
```

화면에 보이는 글은 `본문_소개.md`에 장별로 한 줄에 한 덩이씩 들어 있습니다. 글만 고칠 때는 이 파일을
고치고 다시 빌드합니다. 줄을 더하거나 지우면 구조가 어긋나 빌드가 멈추고, 코드 기준 새 추출본을
`본문_소개.새로추출.md`에 써 줍니다. 장을 더하거나 빼는 일은 `build_deck.py`에서 합니다.

빌드가 금지 기호와 번역투, 헤더 종결어미를 먼저 검사합니다. 화면 문장이 바뀌면 `교정대기_소개.txt`가
생기고 빌드가 멈추므로, 그 문장을 검수하고 고친 뒤 `--approve`로 승인합니다.

덱 오른쪽 위 도구 모음에는 발표자 보기, 번호 이동, PDF 내려받기, 전체보기, 편집이 있습니다. 화면에서
고친 글은 브라우저에만 남으므로, 편집 바의 내보내기로 받은 `편집본_소개.json`을
`python3 apply_edits.py`로 되박아야 다음 빌드에 남습니다.

## 색

로고 파랑 `#3395DA`를 기준으로 삼고, 제목의 강조 낱말과 카드 테두리에 파랑에서 청록으로 가는
그라데이션을 씁니다.

```
#1B6FA8  →  #3395DA  →  #35B4C7  →  #6FD3C7
```

색을 바꾸려면 `deck_theme.py` 위쪽 `:root`의 `--c1`부터 `--c4`와 오로라 네 개의 rgba를 고칩니다.
SVG 안에서 쓰는 같은 그라데이션은 `GRAD_STOPS`가 한자리에서 만들어 냅니다.

## 시연물

이 덱은 시연물을 넣지 않습니다. `시연물/` 은 앞선 프로젝트에서 가져온 틀이고, `data/`의 GA4 원자료는
가져오지 않아 지금은 돌지 않습니다. 새 자료로 쓰려면 다음을 손봅니다.

- `build_graph.py`의 `SITE_HOST`, `PAY_HOST`와 `build_analog.py`의 `HOSTS`를 고객사 도메인으로 바꿉니다
- `campaigns.py`의 `DROP_EXACT`와 `ALWAYS_ON`을 실제 값을 보고 채웁니다
- 화면 문구가 비영리 후원 흐름에 맞춰져 있습니다. `analog_template.html`의 분석 서술은 새 자료에 맞게 다시 씁니다
